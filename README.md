# 페이픽 (PayPick)

내가 가진 결제수단으로 **주변 매장에서 가장 유리한 할인**을 찾아주는 지도 웹앱입니다.
경희대 · 회기역 · 외대앞 일대를 대상으로 한 MVP 시연용입니다.

## 주요 기능

- **결제수단 선택**: 학생 제휴, 통신사 멤버십, 페이, 카드 중 보유한 수단을 고릅니다. 시연 사용자를 선택하면 마이데이터 연결을 가정해 수단을 자동으로 불러옵니다.
- **할인 지도**: 카카오맵 위에 주변 매장을 표시하고, 매장마다 내 수단으로 받을 수 있는 최적 혜택을 보여줍니다.
- **맞춤 정렬**: 맞춤 추천순, 가까운 순, 할인 높은 순으로 정렬하고 업종(음식점, 카페, 편의점, 영화·문화, 학교 제휴, 생활편의)으로 거릅니다.
- **최적 결제수단 추천**: 최소 결제금액, 1회 한도, 월 한도, 전월실적, 제외 브랜드, 중복 적용 여부를 반영해 실제 할인액을 계산합니다.
- **지역화폐 가맹점 확인**: 서울페이·온누리 가맹점 목록과 매장을 이름·주소로 대조해, 확인된 매장에서만 지역화폐 혜택을 적용합니다.

## 실행 방법

빌드 과정이 없는 정적 웹앱입니다.

1. 카카오맵 키 설정

   ```bash
   cp config.example.js config.js
   ```

   `config.js`의 `YOUR_KAKAO_JAVASCRIPT_KEY`를 [카카오 개발자 콘솔](https://developers.kakao.com/)에서 발급한 JavaScript 키로 바꿉니다.
   콘솔의 플랫폼 설정에 실행 주소(예: `http://localhost:8000`)를 허용 도메인으로 등록해야 지도가 뜹니다.

2. 로컬 서버 실행

   혜택 데이터를 `fetch`로 읽기 때문에 `index.html`을 파일로 직접 열면 동작하지 않습니다.

   ```bash
   python -m http.server 8000
   ```

3. 브라우저에서 `http://localhost:8000` 접속

`config.js`는 `.gitignore`에 들어 있어 커밋되지 않습니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조 (1단계 결제수단 선택, 2단계 할인 지도) |
| `styles.css` | 스타일 |
| `app.js` | 화면 로직, 지도 표시, 매장 수집, 혜택 데이터 로드 |
| `engine.js` | 최적 결제수단 추천 엔진 (혜택 적용 판별, 할인액 계산) |
| `data.js` | 결제수단 후보군, 시연 사용자 등 기본 데이터 |
| `config.example.js` | 카카오맵 키 설정 예시 |

혜택 필드 규격은 `engine.js` 상단 주석에 정리돼 있습니다.
